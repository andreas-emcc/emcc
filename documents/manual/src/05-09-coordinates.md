# Coordinates

Settings for how positions are written. A user chooses a format in [Coordinates](03-04-coordinates.md). The format set here is what a user gets until they choose one.

| Setting | What it does | Default |
|---|---|---|
| Default format | The format of positions until the user picks one in this browser: `dd` (decimal degrees), `dms` (degrees, minutes, seconds), `utm` (UTM/UPS) or `mgrs`. Not set: DMS | DMS |
| MGRS precision | The number of digits per axis in MGRS: 5 is 1 m, 4 is 10 m, down to 1, which is 10 km. A whole number from 1 to 5 | 5 |
| DMS seconds decimals | The number of decimals of the seconds in DMS, from 0 to 3 | 1 |
