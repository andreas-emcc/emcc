# Mouse and keys

On a Mac, use Cmd where this page says Ctrl.

## On the map

| Do this | What happens |
|---|---|
| Drag | Moves the map |
| Mouse wheel | Zooms in or out |
| Double-click | Zooms in on the spot. On a cluster, zooms in once |
| Shift and drag | Zooms to a box |
| Click an object | Selects it, and replaces the selection |
| Ctrl and click an object | Adds it to the selection, or removes it |
| Ctrl and drag | Selects the objects in a box |
| Click empty map | Clears the selection |
| Escape | Clears the selection |
| Delete | Deletes the selected objects, after a question |
| Right-click an object | Opens the menu for the selected objects |
| Right-click empty map | Opens the menu with **Centre map** |
| Drag a selected symbol | Moves the symbol |

## While placing a symbol, drawing a shape or placing a graphic

| Do this | What happens |
|---|---|
| Click the map (symbol) | Places a symbol. Placing stays on |
| Press and drag (circle, ellipse, square, rectangle) | Draws the shape |
| Click (area, arrow, route, graphic) | Adds a point |
| Double-click or Enter (area, arrow, route, graphic) | Finishes the shape or graphic |
| Right-click | Removes the last point. With no points left, or when placing a symbol, ends what you are doing |
| Escape | Ends what you are doing. Nothing is saved for an unfinished shape |
| Backspace | Removes the last point |
| Append to a line: click, then double-click or Enter | Adds points after the line's last point, and finishes. Backspace or a right-click takes back the last point you added. Escape cancels |

## In panels and lists

| Do this | What happens |
|---|---|
| Enter or leaving a field | Saves the change |
| Click a row in Objects | Selects the object |
| Ctrl and click a row in Objects | Adds or removes the object in the selection |
| Right-click a row in Objects | Opens the menu |
| Double-click a row in Objects | Zooms the map to the object |
| Arrow keys in Objects | Move between rows |
| Space in Objects | Selects the row |
| Shift+F10 or the menu key in Objects | Opens the menu for the row |
| Click a layer in Layers | Makes it the active layer |
| Space on a layer's name | Makes it the active layer |
| Enter on a layer's name | Opens its objects |
| Double-click a layer | Opens its objects |
| F2 on a layer | Renames it |
| Escape while renaming | Cancels |

## Panes

| Do this | What happens |
|---|---|
| Drag the edge of a pane | Resizes the pane |
| Tab to the edge, then arrow keys | Move the edge in steps of 16 pixels |
| Home or End on the edge | Smallest or largest size |

## Menus and boxes

| Do this | What happens |
|---|---|
| Escape | Closes a menu or box, among them Map controls, Coordinates and Display settings |
| Arrow keys in Bookmarks | Move in the list |
| Enter in Bookmarks | Opens a bookmark or a folder |
| Enter in a field of Go to, Add bookmark or Save setup | Does it |
