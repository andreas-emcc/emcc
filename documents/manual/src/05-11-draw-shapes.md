# Draw shapes

The style that new shapes get in the [Shapes](03-11-shapes.md) panel until a user chooses something else. A user's own choices are kept in the user's browser and win over these.

| Setting | What it does | Default |
|---|---|---|
| Data type | The data type of new shapes. It must be a data type that is available, or General is used | General |
| Outline colour | The colour of the outline of new shapes, as `#rrggbb` | `#1f3a93` |
| Outline width | The width of the outline in pixels, from 1 to 20 | 2 |
| Outline dash | `solid`, `dash` or `dot` | solid |
| Fill | The fill of new shapes that have an area: `none`, `transparent` (a colour and an opacity) or `hatched` (diagonal lines in the fill colour) | none |
| Fill colour | The fill colour when the fill is transparent or hatched, as `#rrggbb` | `#1f3a93` |
| Fill opacity | The opacity when the fill is transparent or hatched, from 0 to 1. 0.2 is 20 % | 0.2 |
