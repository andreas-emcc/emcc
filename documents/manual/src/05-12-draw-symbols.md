# Draw symbols

Settings for the [Symbols](03-09-symbols.md) panel.

| Setting | What it does | Default |
|---|---|---|
| Standard | The APP-6 standard of new symbols: APP-6D or APP-6E | APP-6D |
| Symbol size in the picker | The size of the symbol images in the picker, in pixels, from 16 to 128 | 40 |
| Data type | The data type of new symbols until a user chooses one in this browser. It must be a data type that is available, or General is used | General |
