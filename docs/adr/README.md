# Architecture Decision Records

An Architecture Decision Record (ADR) captures one significant decision: the context, what was decided, the alternatives, and the consequences. ADRs let agents and humans understand **why** the system looks the way it does, without having been part of the discussion.

## Rules

- One decision per ADR. Files are named `NNNN-short-title.md` and numbered in order.
- The ACA writes ADRs. The owner approves them. Only approved ADRs have status **Accepted**.
- Accepted ADRs are never edited, apart from fixing typos and setting the status to *Superseded*. To change a decision, write a new ADR that supersedes the old one, and link both ways.
- To **add to** an accepted decision without changing it, write a new ADR with an `Extends: ADR-NNNN` line. The extended ADR stays unchanged; the index below shows the link, so readers of the older ADR find the newer one.
- **Milestones in an ADR are planning, not part of the decision** (owner, 2026-10-10). An ADR may say in which milestone something is planned. When the owner moves it, only `docs/architecture/overview.md` section 6 changes. The ADR stays as it is, and the index may note the move. Where an ADR and section 6 disagree on a milestone, section 6 is right. This applies to every ADR, also those written before the rule.
- **Names in examples** work the same way. When the owner renames something an ADR uses as an example, for instance a plugin, the ADR stays as it is and the index notes the new name.
- **A later owner decision on a detail** works the same way too (owner, 2026-10-19). When the owner changes a detail of an accepted ADR without asking for a new one, the ADR stays as it is, and the index notes the change with its date and where it is described (the overview, `docs/status.md`). The next ADR on the subject takes it in. A change that reverses a decision point still needs a new ADR, unless the owner chooses this note.
- Statuses: `Proposed` → `Accepted` → (optionally) `Superseded by ADR-NNNN` or `Deprecated`.
- If an agent's work would break an accepted ADR, the agent stops and raises a change request through the MCA.
