## R1, before approval: a sensor report must not carry ground truth

**Problem:** the CR's `Dwell` gives each detection "the detected object's id and content, as the sensor saw it". A GMTI radar measures a position, a time and a radial speed. It does not know a track's id, identity, symbol or name.
- If those pass through, `cot`, `ais` and `adsb` send the true identity and name in a **Sensor output** (ADR-0048 point 4).
- A Sensor output would then look like a Ground truth output with noise, which the owner's Q6 split was meant to prevent.

**Proposal for question 7:**
- A detection carries what its sensor type measures. For the GMTI sensor in M5, that is the measured position, with the sensor's errors in it, the time and the radial speed.
- It also carries **a key per sensor and detected object,** so that an output that needs an id has a stable one, for example `cot`'s uid. This key is not the object's own id.
- Outputs map such a detection with an **unknown identity** and no name.
- A later sensor type that receives what targets report about themselves (an AIS or ADS-B receiver) may carry what those reports carry. Its brief says so.

**Fix:** the PDA, in `Dwell`'s shape and in the simulator's and `gmti`'s briefs, after the owner answers question 7. If the owner wants ground truth identities in sensor outputs instead, ADR-0048 needs an index note saying so (ACA).

## R2, after question 4: record the new file rule

Answering question 4 with "the SDK reads" changes two things:
- **ADR-0049 points 4 and 6:** ECore, not the plugin, opens files and checks paths.
- **A rule plugins did not have in writing:** they read local files only through the SDK's declared folders, never with their own I/O. Today it lives only in `PluginRules`.

**Fix (ACA, after the owner's answer):**
- an index note on ADR-0049;
- one normative sentence in overview 4.1;
- a clause in `CLAUDE.md` section 4 beside "Storage only through the persistence manager", for the owner's approval.

**For `terrain`'s GeoTIFF library** (ADR-0049 point 6): it must parse bytes or streams handed to it by `LocalFolder.read`. It must never open a path itself. The PDA states this in the brief, and the owner's approval of the library checks it.
